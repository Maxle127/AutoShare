# AutoShare — frontend

AutoShare — вебзастосунок для оренди автомобілів у Закарпатті.

## Стан проєкту

У межах лабораторної роботи №3 створено каркас frontend та
налаштовано інструменти розробки. Файли сторінок є заготовками.
Верстка, маршрутизація та бізнес-логіка реалізовуватимуться
в наступних лабораторних роботах.

## Стек

- React і TypeScript — розробка інтерфейсу.
- Vite — сервер розробки та збірка.
- ESLint — перевірка коду.
- Prettier — форматування.
- Vitest і React Testing Library — тестування компонентів.
- Cypress — E2E-тестування у браузері.
- Husky — запуск перевірок перед комітом.

## Структура

| Шлях | Призначення |
|---|---|
| src/pages/ | Заготовки каталогу, сторінки авто, кабінету та входу |
| src/components/ | Місце для спільних компонентів |
| src/assets/ | Зображення та інші ресурси |
| src/styles/ | Місце для спільних стилів |
| src/test/ | Налаштування юніт-тестів |
| src/App.tsx | Кореневий компонент |
| src/main.tsx | Точка входу застосунку |
| src/App.test.tsx | Тести стартового компонента |
| public/ | Статичні файли |
| cypress/e2e/ | E2E-тести |
| .husky/pre-commit | Перевірки перед комітом |

Структура розділяє сторінки, спільні компоненти, ресурси та тести.
Цього достатньо для поточного масштабу проєкту, а призначення
кожної папки зрозуміле з її назви.

## Встановлення та запуск

Потрібні Node.js і npm. Після клонування репозиторію:

```sh
cd frontend
npm install
npm run dev
```

У Windows PowerShell за потреби використовуйте `npm.cmd` замість
`npm` і `npx.cmd` замість `npx`.

## Команди

| Команда | Призначення |
|---|---|
| npm run dev | Сервер розробки |
| npm run build | Перевірка TypeScript і збірка |
| npm run preview | Перегляд зібраного застосунку |
| npm run lint | Перевірка ESLint |
| npm run format | Форматування файлів |
| npm run format:check | Перевірка форматування |
| npm run test | Юніт-тести в режимі стеження |
| npm run test:run | Одноразовий запуск юніт-тестів |
| npx cypress open | Відкриття Cypress |

## Тести

Два тести Vitest перевіряють заголовок стартового компонента
та збільшення лічильника.

Один E2E-тест Cypress перевіряє відображення заголовка та
роботу лічильника в браузері. Перед запуском потрібно запустити
`npm run dev`. Тест очікує застосунок на http://localhost:5173.

## Git hooks

Скрипт prepare налаштовує Husky після встановлення залежностей.

Перед комітом автоматично виконуються:
1. Перевірка форматування.
2. ESLint.
3. Юніт-тести.

Якщо перевірка завершується помилкою, коміт зупиняється.
